> First, I create an empty list called `tasks` to store the tasks later. Then I use a `while` loop so the program keeps running. After that, I check the user's choice using `if` and `elif`.
>
> If the choice is **1**, the user enters a new task, the task is added to the list, and the program prints **"Task added successfully!"**.
>
> If the choice is **2**, the loop goes through the list and prints each task with its number.
>
> If the choice is **3**, the user enters the task number, and the program changes its status by adding **"(Done)"** to the task.
>
> If the choice is **4**, the user enters the task number to remove it. We use num-1 because Python list indexing starts from 0
>
> If the choice is **5**, the program prints Good bye and uses `break` to stop the loop and close the program.
>
> If the user enters any other number the program prints Invaild choice.
